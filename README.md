# Digital IC Trainer

An interactive simulator of the Sastha's Digital IC Trainer Kit for the Digital Design lab
(25CS1733): build the lab circuits on a 2D or 3D board, check them against the expected
truth tables, and study the guide, viva questions and quizzes.

Open it: https://bharadwaj-exe.github.io/digital-ic-trainer/

This repository contains only the built website. It is published automatically from the
source repository (build 05b8140).
